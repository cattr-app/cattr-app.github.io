∗ Notice that Cattr for Windows is not popular enough yet to pass Microsoft SmartScreen's protection, so you probably will experience SmartScreen popup warning on application launch. To allow Cattr to run on your PC, click "More info" then "Run anyway" button in the SmartScreen popup. If you feel unsafe doing this, you can build a desktop application from source code by yourself using the link below.

Here is the desktop application source code repository: cattr-app/desktop-application.

* Обратите внимание, что Cattr для Windows еще недостаточно популярен, чтобы пройти защиту Microsoft SmartScreen, поэтому вы, вероятно, увидите всплывающее предупреждение SmartScreen при запуске приложения. Чтобы разрешить запуск Cattr на вашем ПК, нажмите «Подробнее», а затем кнопку «Запустить в любом случае» во всплывающем окне SmartScreen. Если вы чувствуете себя небезопасно, Вы можете создать приложение для компьютера из исходного кода самостоятельно, используя ссылку ниже.

Репозиторий исходного кода настольного приложения:: cattr-app/desktop-application.
